# ChiyoRush

千代田線の列車のうち、小田急線・常磐線に直通しない列車（千代田線内で始発・終着になる列車）を見分ける時刻表のページです。

- ページ: https://gracom.github.io/chiyorush/
- 1枚のHTML（`index.html`）に時刻表を埋め込んであり、ページの外へは通信しません。
- 選んだ駅と方面は、そのブラウザのCache Storageとクッキーにだけ残ります。

## データの出典

公共交通オープンデータセンター（ODPT）の東京メトロの列車時刻表をもとにしています。

- 内容の正確性・完全性は保証されません。遅延や運転見合わせは反映されません。
- 表示内容について、東京メトロへ直接お問い合わせにならないようお願いします。
- このページへのお問い合わせは、このリポジトリのIssueからお寄せください。
